## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | EventController GET /api/events — category, city, status, dateFrom, dateTo query params | mitigate | EventSpecification uses JPA Specification / parameterized PreparedStatement for all predicates — user input is never concatenated into JPQL strings |
| T-02-08 | Tampering | PATCH /api/events/{id} — EventStatus field injection via request body | mitigate | UpdateEventRequest has no EventStatus field (D-16); EventMapper.updateEventFromRequest has @Mapping(target="status", ignore=true) — defense-in-depth; status cannot change via PATCH regardless of request body content |
| T-02-09 | Elevation of Privilege | DELETE /api/events/{id} — deleting published events | mitigate | EventService.delete() enforces DRAFT-only guard per D-06; throws HTTP 409 CONFLICT for any other status — no auth bypass possible because guard is unconditional |
| T-02-10 | Elevation of Privilege | POST /api/events/{id}/publish,start,cancel,complete — invalid transitions | mitigate | Each action method checks exact current status and throws HTTP 409 CONFLICT on violation; terminal states (COMPLETED, CANCELLED) can never be transitioned out of |
| T-02-11 | Information Disclosure | GET /api/events/{id} — exposing internal IDs | accept | UUIDs are non-sequential and computationally infeasible to enumerate; response DTOs do not expose entity internal metadata beyond what the API contract requires |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
</threat_model>
